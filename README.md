# Writenestia website — v0.4

Static presentation site for **Writenestia v0.4 for Windows**.

## Included

- Updated v0.4 content and screenshots
- Light/dark theme switch
- Theme preference saved in the browser
- Responsive layout
- Screenshot gallery with lightbox
- Version 0.4 planning section
- Languages: English, Português (Brasil), Español
- itch.io download/embed
- No external framework required

## Files

```text
index.html
styles.css
script.js
assets/
└── images/
```

## View locally

```powershell
python -m http.server 4173
```

Then open `http://localhost:4173`.

## Hosting

The site can be uploaded directly to Cloudflare Pages, GitHub Pages, Netlify, Vercel or any static host.
